# Iglesia Pentecostal - Website Moderno

## 📋 Descripción
Sitio web profesional para una iglesia cristiana pentecostal, construido con React + TypeScript + Vite.

## 🚀 Características
- ✅ Diseño responsive y moderno
- ✅ Sección de servicios y eventos
- ✅ Blog con filtrado por categorías
- ✅ Integración con redes sociales
- ✅ Formulario de contacto con validación
- ✅ Header fijo con logo
- ✅ Deployment listo para Netlify

## 🛠️ Tecnologías
- **React 18** - Biblioteca frontend
- **TypeScript** - Tipado estático
- **Vite** - Build tool rápido
- **React Icons** - Iconografía
- **CSS Modules** - Estilos modulares
